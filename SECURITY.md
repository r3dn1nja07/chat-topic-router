# Security and privacy reports

Please do not open a public issue containing private AI conversation text, account details, source conversation URLs, credentials, or other sensitive information.

For a suspected security or privacy flaw, report the behavior privately to the repository owner once the public repository is created. Until a private reporting channel is configured, use placeholder text in public issues and do not attach exported backups.

The extension is designed to store routed passages locally in the browser profile. Backups are plain JSON and can contain private text; users should protect those files accordingly.
