# v0.5.1 — Clipboard error feedback

Fixed **Copy cited context** when the browser refuses clipboard access. Router now shows **Copy blocked** and explains how to copy the text and citation manually. Successful copies keep the same text and source citation.

Added regression coverage for clipboard denial, safe result rendering, offline search, failed capture recovery, and disconnect. No new permissions or changes to stored passages, pairing, search, or capture behavior.

Download **Source code (zip)** from this release, extract it, and reload the unpacked extension from the updated folder. The optional central brain bridge and pairing setup are unchanged. This patch retains the pre-release status of v0.5.0.
